개인정보 처리방침

개정일: 2026년 10월 20일 · 1.0.2 이상 버전에 적용합니다. 1.0.1 이하 버전은 앱 사용 분석을 수집하지 않습니다.

1. 기기에 저장하는 정보

알바췍은 회원가입이 없습니다. 입력한 근무지명·근무 기록·시급·받은 금액은 기기에 저장되며 사용 분석을 위해 전송하지 않습니다.

2. 선택적 앱 사용 분석

앱 사용 분석에 동의하면 Google Analytics for Firebase를 통해 근무지 등록·첫 근무 저장·급여 조회·앱 활성 및 재방문 이벤트와 앱 버전·운영체제·기기 정보, 접속 IP 기반 대략적인 지역 정보, 분석용 앱 인스턴스 식별자를 Google로 전송합니다. 이벤트에는 근무지명, 근무 날짜·시간, 시급·급여 금액을 포함하지 않습니다. 광고 식별자 수집과 광고 개인화는 사용하지 않습니다. Google 서비스의 처리 위치에 따라 국외에서 처리될 수 있습니다. 동의하지 않아도 모든 기능을 사용할 수 있습니다.

분석 데이터 보관: GA4의 이벤트 데이터 보관 설정은 2개월, 사용자 데이터는 마지막 활동부터 14개월입니다. 보관 기간이 지나면 Google의 정기 삭제 절차에 따라 삭제됩니다. 개인별 상세 데이터와 별개인 집계 보고서는 이 기간의 적용을 받지 않습니다.

4. 공유와 백업

급여명세서·메시지 공유와 백업 파일 저장은 사용자가 직접 고른 앱과 위치로만 전달됩니다. 분석 동의와 분석 이력은 백업에 포함되지 않습니다.

5. 분석 중단과 삭제

전체 > 앱 사용 분석에서 참여를 끄면 추가 분석 수집을 중단하고 기기에 저장된 Google 분석 데이터와 식별자를 초기화합니다. 이미 Google로 전송된 데이터가 이 동작으로 삭제되지는 않습니다. 앱 삭제·앱 데이터 삭제는 기기에 저장된 근무 기록과 분석 설정을 지웁니다.
