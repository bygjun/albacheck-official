자주 묻는 질문

알바췍은 어떤 앱인가요?+

근무 조건과 출퇴근 기록을 바탕으로 예상 급여를 계산하고, 실제 받은 금액과 비교할 수 있는 안드로이드 앱입니다. 주휴수당과 수당·공제 내역도 입력 조건에 따라 확인할 수 있습니다.

회원가입이 필요한가요?+

회원가입 없이 시작할 수 있습니다. 근무지·근무 기록·받은 금액은 앱을 사용하는 기기 안에 저장됩니다.

아이폰에서도 사용할 수 있나요?+

이 홈페이지에서 안내하는 설치 버전은 Google Play의 안드로이드 앱입니다. 아이폰용 설치 링크는 제공하지 않습니다.

예상 급여가 실제 지급액과 같은가요?+

입력한 근무 조건과 기록에 따른 참고 금액입니다. 시급 적용일, 정산 기간, 휴게시간, 수당·공제 조건과 실제 급여명세서를 함께 확인해 주세요.

문의 문장이 사장님께 자동으로 전송되나요?+

자동 전송되지 않습니다. 앱에서 만든 문장의 근무지 이름, 날짜, 금액과 표현을 직접 검토한 뒤 공유할 곳을 선택합니다.

휴대폰을 바꾸면 기록은 어떻게 옮기나요?+

기존 폰에서 전체 → 백업 → 백업 파일 저장을 사용하세요. 파일을 새 폰으로 옮긴 뒤 백업 파일 불러오기로 가져올 수 있습니다. 불러오면 현재 기록이 백업 내용으로 바뀌므로 먼저 보관할 기록을 확인해 주세요.
